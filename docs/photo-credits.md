# Portrait credits

PitWall displays a small, curated set of editorial driver portraits hosted by Wikimedia Commons. Portraits are archival and may not depict the selected race or season. They are shown in grayscale and cropped by the page layout. Each portrait links to its original file page, which includes the full licence and any additional conditions. If a portrait cannot load, PitWall displays the driver's acronym instead. Other drivers also use this fallback.
